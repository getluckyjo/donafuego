# Doña Fuego — Brand Kit

Everything needed to make content that looks and sounds like Doña Fuego.
Drop this whole folder in the shared Drive and work out of it.

## Start here

| File | Read it when |
|---|---|
| `Brand-Sheet.pdf` | You want the palette and type on one page. Print it. |
| `01-brand.md` | You're new to the brand, or writing a brief |
| `02-voice.md` | You're writing a caption, an email or an ad |
| `03-colour.md` | You're designing anything |
| `04-typography.md` | You're setting type |
| `05-photography.md` | You're editing shoot images or briefing a shoot |
| `06-social-specs.md` | You're building the calendar or exporting assets |
| `07-compliance.md` | **Before anything goes live or gets boosted. Every time.** |
| `claude-context.md` | You're using Claude — paste this in first |
| `design-tokens.css` | You're building anything on the web |

## Assets

- `assets/fonts/` — Bevan, Oswald, Work Sans as woff2. Self-host these, don't link to Google.
- `assets/cans/` — Margarita, Paloma, Spicy Margarita renders on white.
- `source/` — the file that generates the brand sheet. Ignore it unless you're editing the sheet.

## The rule that matters most

The brand is warm, hand-made and unfussy. If a piece of work looks
expensive, corporate, or like it came from a template, it's wrong —
even if every colour and font in it is technically correct.

## Keeping it current

One person owns this folder. If a rule changes, change it here first and
tell everyone, rather than letting three versions drift apart in
different decks.
